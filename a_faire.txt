A very simple method is to sum all samples above or under the silence level. If the absolute sum exceeds some threshold, it may have been a bass or bass drum.
Below is the code to calculate the sum. Put it in the the render function of a vis plugin and make sure you get the waveformdata. Of course, the code is too simple, because it only checks the left channel, uses a fixed threshold etc., but maybe you can use it.
int x, data1, sum = 0, threshold = 4000;
for (x = 0; x < 576; x++)
{
data1 = ((this_mod->waveformData[0][x]^128)>>(this_mod->nCh-1)) - 64;
if ((sum ^ data1) & 0x8000) // check if sign is different
sum = 0;

sum = sum + data1;
if ((sum > threshold) | | (sum < -threshold))
{ // May be a beat, do something...
}
}
