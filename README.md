# Space
Originally created by flemteam A.K.A. Pascal Dallongeville, as a downloadable visualization plugin for [Winamp](https://winamp.com/), and most known for being bundled with the [JetAudio](http://www.jetaudio.com/) music player.

<img width="881" height="610" alt="space" src="https://github.com/user-attachments/assets/7ffa1220-e3fe-4788-8c21-548599110878" />


This repository is the extracted source-code for the Space visualization (from its .ace file, sourced from [winamp-libre-archive](https://github.com/winamp-libre/winamp-libre-archive)). 

If anyone wants to port this visualization to media centers/players like [foobar2000](https://www.foobar2000.org/) (version 2.24 and later), [VLC](https://www.videolan.org/index.html) (version 3.0.0 and later), [Kodi](https://kodi.tv/) (version 21.0 and later) and [AIMP](https://aimp.ru/) (version 5.00 and later), you can use this source code.

The binary for the pre-built Winamp plugin is at the Releases page.
