# Space
Originally created by flemteam A.K.A. Pascal Dallongeville, as a downloadable visualization plugin for [Winamp](https://winamp.com/), and most known for being bundled with the [JetAudio](http://www.jetaudio.com/) music player.

<img width="881" height="610" alt="space" src="https://github.com/user-attachments/assets/7ffa1220-e3fe-4788-8c21-548599110878" />


This repository is the extracted source-code for the Space visualization (from its .ace file, sourced from [winamp-libre-archive](https://github.com/winamp-libre/winamp-libre-archive)). If anyone wants to port this visualization to media centers/players like [VLC](https://www.videolan.org/index.html) (version 3.0.x and later), [Kodi](https://kodi.tv/) (21.3+) and [AIMP](https://aimp.ru/) (versions 5.00 or later), you can use this source code.

The binary for the pre-built Winamp plugin is at the Releases page.
